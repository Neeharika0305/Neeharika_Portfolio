Relay

Globally Scalable Intelligent URL Routing & Reliability Platform

View on GitHub ↗

A backend infrastructure platform designed to make request routing more intelligent, reliable and observable across multiple upstream services.

Relay evaluates service and traffic conditions to select appropriate upstream targets using multiple routing strategies, including weighted, priority, least-load and latency-aware routing.

PostgreSQL acts as the persistent source of route configuration, while Redis provides low-latency access to frequently used routing data. The platform also performs active health checks and automatically removes unhealthy services from routing decisions.

Reliability mechanisms include automatic failover, rate limiting, circuit-breaker behavior and canary routing. Prometheus and Grafana provide operational visibility into routing behavior, service health and system performance.

CampusInox

Smart Campus Issue Intelligence & Resolution Platform

View on GitHub ↗

A full-stack platform for reporting, analyzing and managing campus issues through a structured resolution workflow.

CampusInox provides a centralized system where users can report campus problems while administrators can review, prioritize, investigate and track issues through their complete lifecycle.

The React frontend communicates with a Flask REST API, while MySQL provides persistent storage for users, issues and workflow data. JWT authentication and role-based access control separate student and administrative capabilities.

NLP-based similarity analysis helps identify potentially duplicate reports, while classification and priority analysis support faster and more consistent issue triage.

VaultBox

Secure Authentication & Encrypted Data Management

View on GitHub ↗

A security-focused web application designed around authenticated access and protected management of sensitive application data.

VaultBox uses Flask as the application layer and MySQL for persistent storage, providing a structured backend for authenticated users and protected resources.

Authentication workflows incorporate PyOTP-based time-based one-time passwords, adding an additional verification layer beyond standard credentials.

Sensitive data is protected using Fernet-based symmetric encryption. The project demonstrates practical application-security concepts including authentication, multi-factor verification, encrypted data handling and controlled access to protected resources.
